# 真题库、知识库、RAG 与记忆系统重构设计

- 日期：2026-07-25
- 状态：设计已确认，待实施计划
- 验收等级：L3
- 适用范围：主应用 `frontend/`、`backend/langdrill_agent/` 与 `演示web2/`

## 1. 背景与现状

当前真题库主要围绕远程来源同步、检索和蒸馏展开，本地文件导入能力仍分散在旧设置入口，真题库页面没有统一的本地文件或截图导入体验。知识库已有单文件选择和后端导入接口，但缺少拖拽、多文件队列、解析预览和确认入库流程。

当前知识库没有启用嵌入模型。本地环境未配置 `LANGDRILL_KNOWLEDGE_EMBEDDING_*`，因此运行时只使用 SQLite FTS5 全文检索。现有后端支持通过环境变量连接外部嵌入服务，但未提供完整的用户可见模型选择、下载、索引管理和安全状态。

当前记忆设置直接暴露较多内部分类和技术参数，默认核心记忆与召回预算分别约为 400 和 1200 token，无法满足长周期学习场景，也不利于普通用户理解。

`演示web2` 的在线体验入口应继续指向实验版；下载区域需要区分稳定版和实验版，其中 `v0.1.2` 仅在演示站中显示为稳定版，不修改 GitHub Release 原有属性。

## 2. 设计目标

1. 真题库允许上传本地 PDF、DOCX、TXT、Markdown 和图片，截图可直接作为真题来源。
2. 知识库允许点击选择或拖拽上传多个文件，并在正式写库前完成解析预览。
3. 真题库、知识库使用一致的“选择文件—解析—预览—确认入库”交互，但保持在各自原有页面和视觉风格中。
4. RAG／向量增强检索由用户主动开启，默认关闭；关闭时继续可靠使用 FTS5。
5. 用户可选择本地 Hugging Face 嵌入模型、Hugging Face 云端推理或 OpenAI-compatible 云端嵌入接口。
6. 提供经过验证的推荐嵌入模型，并允许搜索和下载 Hugging Face 上任意兼容的嵌入模型。
7. 记忆设置简化为三档模式和三个用户可理解的分组，同时保留可折叠的开发者选项。
8. `演示web2` 下载区提供稳定版和实验版选择，在线体验入口不改变。

## 3. 非目标

1. 不重做主应用导航、主题或卡片视觉体系。
2. 不创建独立的“导入中心”；真题导入留在真题库，知识导入留在知识库。
3. 不默认启用 RAG，不自动下载模型，不自动调用云端嵌入服务。
4. 不修改 GitHub Release 的 Pre-release 标记。
5. 不在本阶段引入独立 TEI 服务、Docker 模型服务或默认 ONNX 推理链路。
6. 不允许未经验证的模型仓库自定义代码在本地执行。

## 4. 总体架构

### 4.1 文件导入

前端提供共享的底层文件导入组件和状态模型，支持拖拽、文件选择、多文件追加、单项删除、解析状态和错误显示。真题库、知识库在现有页面中分别组合该组件并提供领域专属预览；截图导入在不改变既有流程的前提下复用低层文件列表和拖拽能力。

后端增加统一的临时暂存与解析服务：

1. 接收文件并生成暂存任务，不写入正式业务表。
2. 使用现有文本抽取、MinerU 和 RapidOCR 能力解析。
3. 返回结构化预览、诊断和可编辑元数据。
4. 用户确认后，由真题或知识库领域服务完成正式入库。
5. 取消、过期或成功入库后清理临时数据。

真题库预览至少包含标题、年份、识别题型、题目数量、答案可信度、短文本预览和警告。知识库预览至少包含标题、语言、页数或内容长度、切块数量、文本预览和警告。

### 4.2 嵌入与混合检索

检索服务提供统一的嵌入供应商接口：

- `off`：仅使用 SQLite FTS5。
- `local`：本进程按需加载 `sentence-transformers` 兼容模型。
- `huggingface_cloud`：调用 Hugging Face Inference。
- `openai_compatible`：调用兼容 OpenAI Embeddings 的云端接口。

本地方案采用 Python 进程内延迟加载。用户确认后才安装可选运行依赖、下载模型或加载模型；模型空闲时允许卸载。模型存储目录可配置，默认不强制写入 C 盘。

混合检索以 FTS5 为稳定基础，RAG 开启后叠加向量召回，并通过归一化融合和 MMR 去重重排。任意嵌入失败均不得中断关键词检索。

### 4.3 推荐与任意 Hugging Face 模型

默认推荐模型为：

- `Qwen/Qwen3-Embedding-0.6B`：默认推荐，小体积、多语言、适合本地运行。

实现时再基于兼容性、许可证、模型格式、体积和多语言能力补充少量推荐项。推荐项不是硬编码下载入口，仍通过统一 Hugging Face 模型目录读取详情。

任意模型搜索只允许候选模型进入“待验证”状态。启用前必须验证：

- 任务类型与 embedding/feature-extraction 兼容。
- 存在可支持的模型格式与 tokenizer。
- 不依赖 `trust_remote_code`。
- 输出为稳定、非空、固定维度的数值向量。
- 许可证和模型信息可展示。

不满足条件的模型可以查看，但不能启用。

### 4.4 记忆策略

前端只暴露三个记忆分组：

- 关于我：用户画像、目标、偏好。
- 学习记录：弱项、掌握度、阶段表现。
- 使用习惯：讲解风格、工作流偏好、长期指令。

后端保留现有细分类，使用策略适配层把内部类别映射到三个用户分组，避免数据库迁移和既有行为被无必要破坏。

记忆模式：

- 节省：最多 5,000 token。
- 标准：最多 10,000 token，默认。
- 深入：无固定 token 上限，但必须为系统指令、当前对话、当前问题和回答预留至少 30% 的上下文。

召回排序综合相关性、近期性和证据强度。深入模式空间不足时先压缩低优先级记忆，再减少召回数量，不能侵占回答保留空间。

### 4.5 演示站发布通道

`演示web2` 使用明确的下载通道配置：

- 稳定版：`v0.1.2`。
- 实验版：`v1.0.0-alpha.2`。

该分类只影响演示站展示。在线体验入口继续进入实验版，不新增稳定版在线体验入口。

## 5. 交互与数据流

### 5.1 文件导入

1. 用户拖拽或选择一个或多个文件。
2. 文件先进入前端待处理队列，可继续追加或删除。
3. 用户点击“解析”后才上传暂存并启动抽取、OCR 和诊断。
4. 后端返回逐文件解析结果，前端显示结构化预览。
5. 用户可修改标题、年份、标签等元数据，也可修正内容后重新解析。
6. 用户点击“确认入库”后，后端在事务或可恢复流程中写入正式数据和资产。
7. 成功项从暂存区清理；失败项保留错误和重试入口。

批量任务允许部分成功，但正式入库结果必须逐项清晰展示。

### 5.2 RAG 设置

RAG 默认关闭。设置页提供：

1. 关闭：说明当前使用 FTS5，不加载、不下载、不调用云端模型。
2. 本地模型：展示推荐模型、Hugging Face 搜索、已下载模型和存储目录。
3. 云端模型：选择 Hugging Face Inference 或 OpenAI-compatible，并配置连接信息。

下载前必须展示模型 ID、revision、许可证、格式、预计大小、目标目录和磁盘空间。用户明确确认后才开始下载。下载完成只表示“可用”，仍需用户主动启用。

切换供应商、模型、revision 或向量维度时，界面提示相关知识库、真题库和记忆向量需要重新索引，不进行静默重建。

### 5.3 记忆设置

记忆页默认只展示：

- 节省、标准、深入三档选择。
- 关于我、学习记录、使用习惯三个分组开关。
- 每条记忆的来源、证据、更新时间和版本。
- 分组清理和全部清理入口。

证据数量、置信度、TTL、召回数量、写入策略、嵌入状态等技术参数收进“开发者选项”，普通用户不需要理解这些参数即可获得合理默认行为。

## 6. 数据与配置

非敏感配置、模型元数据、下载任务状态、嵌入身份和索引状态写入 SQLite。云端密钥和 Token 只写入本地 `.env`，前端和 API 只获得是否配置及脱敏预览。

每份向量索引绑定完整身份：

`provider + model_id + revision + dimensions`

不同身份的向量不能混用。身份变化后旧索引标记为过期，继续使用 FTS5，直到用户确认并完成重新索引。

本地模型目录可由用户配置。模型文件不进入 Git，不随演示站发布，也不写入项目源码目录。

## 7. 安全、异常处理与降级

### 7.1 导入安全

- 设置单文件大小、批量数量和文件类型限制。
- 规范化文件名，禁止路径穿越和覆盖任意文件。
- 临时文件带过期时间并支持后台清理。
- 每个文件独立解析和报错，单个失败不阻塞整批。
- 正式入库前不修改业务数据。
- 清空队列、删除已入库资料或覆盖同名资产前二次确认。

### 7.2 模型安全

- 仅通过 HTTPS 和 Hugging Face 官方接口检索与下载。
- 默认并强制禁用 `trust_remote_code`。
- 下载前检查磁盘空间，支持进度、取消、断点续传和失败重试。
- 对下载结果记录明确 revision，并在可行时校验文件元数据或摘要。
- 下载后执行加载、向量维度和最小推理健康检查，通过后才允许启用。
- 下载、加载或推理失败时回退 FTS5，并明确显示 RAG 未生效。

### 7.3 云端安全

- 密钥只保存在 `.env`，日志、API 返回、进展文档和演示站均不得包含明文。
- 保存配置前提供显式连接测试。
- 对限流、超时、鉴权失败、维度不符分别提示。
- 云端不可用时不阻塞关键词检索。

### 7.4 记忆与上下文保护

- 深入模式始终预留至少 30% 上下文。
- 上下文不足时按优先级压缩或减少记忆。
- 清理记忆前展示影响范围并二次确认。
- RAG 或记忆检索失败不得伪装成成功召回。

### 7.5 演示站链接

构建时验证稳定版和实验版下载地址存在且可访问；链接无效时构建或发布检查应失败，而不是发布不可用按钮。

## 8. 测试与验收

### 8.1 后端自动测试

- 暂存、解析、预览、确认、取消和过期清理。
- PDF、DOCX、TXT、Markdown 和图片解析。
- 批量部分失败、重复文件、非法格式和超限文件。
- Hugging Face 搜索、下载确认、取消、恢复和兼容性验证。
- 远程代码禁用、磁盘不足、加载失败及 FTS5 降级。
- RAG 开关、混合检索、嵌入身份和重新索引。
- 三档记忆预算、三类映射和深入模式 30% 预留。

### 8.2 前端自动测试

- 真题库和知识库的拖拽、点击选择及多文件队列。
- 解析预览、元数据编辑和确认入库。
- RAG 关闭、本地、云端三种状态。
- 推荐模型、任意模型搜索、下载确认和状态进度。
- 模型切换后的重建索引提示。
- 记忆模式、三个分组和开发者选项。
- 演示站稳定版、实验版下载和实验版在线体验入口。

### 8.3 本地端到端与人工验收

- 分别用 PDF 和截图向真题库、知识库导入资料。
- 确认解析前和预览阶段不会写入正式数据。
- 对比 FTS5 与 RAG 检索结果。
- 下载并启用 `Qwen/Qwen3-Embedding-0.6B`，重启后验证模型与索引状态。
- 模拟模型损坏、下载中断、网络异常和云端接口失败。
- 检查 `.env`、日志、浏览器响应和演示站无密钥泄露。
- 回归三栏学习、截图导入、真题同步和知识库检索。
- 记录模型下载体积、首次加载耗时和实际内存占用。

### 8.4 交付门槛

本任务验收等级为 L3。只有自动测试、核心人工流程和相关健康功能回归均通过，任务验收结论才可记为“通过”并合并 `main`。如真实模型下载或设备资源测试尚未执行，结论不得直接记为“通过”。

## 9. 实施拆分建议

后续实施计划按以下模块拆分：

1. 暂存导入服务与共享前端导入组件。
2. 真题库本地文件／截图导入。
3. 知识库拖拽与批量预览导入。
4. 嵌入供应商、模型目录、下载任务与安全校验。
5. FTS5＋向量混合检索与索引身份管理。
6. 记忆三档策略与简化界面。
7. `演示web2` 下载通道。
8. 自动测试、端到端测试、人工验收与文档更新。
