# Lang Drill Agent 验收标准

## 测试环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10.0.26200 x64 或同等 Windows（视窗系统）环境 |
| 后端 | FastAPI（Web API 框架）开发服务 `http://127.0.0.1:8000` |
| 前端 | Vite（前端构建工具）开发服务 `http://127.0.0.1:5173` |
| 数据库 | SQLite（轻量数据库），正式学习状态以数据库为唯一来源 |
| 模型 | 普通 Web（网页）模式默认真实 provider（供应商）MiMo（小米米魔）；mock（本地模拟）provider 只用于自动测试或离线调试 |

| 项 | 内容 |
|---|---|
| 验收步骤 | 双击 `start.bat`。 |

| 结果记录 | 2026-06-30 `start-dev.ps1 -NoBrowser -SkipInstall` 自动验证通过，5173 / 8000 返回 200；脚本已覆盖 API Key（接口密钥）前缀规范化；双击体验待人工确认。 |
| 反馈/问题 | 如服务失败，启动器必须输出错误并展示对应日志尾部，不能在未监听端口时直接打开浏览器；PowerShell（命令行脚本）内识别中文全角冒号必须使用编码安全的正则转义。 |

## 7. 聊天栏模型与思考等级

| 项 | 内容 |
|---|---|
| 验收步骤 | 在设置中配置 OpenAI/GPT、Claude、DeepSeek（深度求索）或 MiMo（小米米魔）的 API Key（接口密钥），再在聊天栏上方切换模型供应商、模型名称和思考等级；对当前模型点击“添加思考等级”后保存。 |
| 预期结果 | 未配置 API Key（接口密钥）的真实供应商不出现在聊天栏快捷模型选择；自定义供应商未添加前不出现。配置立即保存到后端模型配置；下次发送消息使用新的 provider（供应商）、model（模型）和当前模型的原生 thinking level（思考等级）。没有原生档位且未自定义添加档位的模型不显示思考等级选择。 |
| 证明方式 | 自动测试 `py -m pytest try/test_model_config.py try/test_provider_reasoning.py -q`；前端构建命令 `npm run build` 通过；人工确认聊天栏只显示已配置密钥供应商，设置页可新增当前模型思考等级。 |
| 结果记录 | 2026-06-30 模型配置、供应商调用和启动脚本自动测试通过；启动脚本健康检查通过；前端构建通过；人工确认待执行。 |
| 反馈/问题 | 原生参数按模型配置写入：OpenAI-compatible（OpenAI 兼容）使用 `reasoning_effort`（推理强度），DeepSeek V4 使用 `thinking` + `reasoning_effort`，Claude 使用 Anthropic Messages（Anthropic 消息接口）的 `thinking` 和 `output_config.effort`，MiMo 使用 Anthropic Messages 的开关式 `thinking`。API Key（接口密钥）保存/读取和启动脚本保留密钥时会清理常见 `apikey:` / `Bearer:` 粘贴前缀，非法请求头字符必须返回可读配置错误。禁止用提示词模拟思考等级。 |
| 最终结论 | 待定。 |
