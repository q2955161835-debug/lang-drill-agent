# Lang Drill Agent 验收标准

## 测试环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10.0.26200 x64 或同等 Windows（视窗系统）环境 |
| 后端 | FastAPI（Web API 框架）开发服务 `http://127.0.0.1:8000` |
| 前端 | Vite（前端构建工具）开发服务 `http://127.0.0.1:5173` |
| 数据库 | SQLite（轻量数据库），正式学习状态以数据库为唯一来源 |
| 模型 | 可用真实 provider（供应商）或 mock（本地模拟）provider；无真实 API key（接口密钥）时只验结构流 |

| 结果记录 | 待人工确认。 |
| 反馈/问题 | 如服务失败，查看两个日志文件定位。 |
| 最终结论 | 待定。 |

## 3. 正式题组先入库再展示

| 项 | 内容 |
|---|---|
| 验收步骤 | 输入一组词汇或学习请求，例如 `blood: n. 血液`，触发日常训练。 |

| 证明方式 | 自动测试 `py -m pytest try/test_formal_drill_flow.py -q`；数据库中同一 `session_id` 下存在多条 `questions` 记录。 |
| 结果记录 | 待自动验证。 |
| 反馈/问题 | 真实模型不可用时允许 fallback（兜底）题组，但仍必须多题入库。 |
| 最终结论 | 待定。 |

| 证明方式 | 自动测试 `py -m pytest try/test_formal_drill_flow.py -q`；`attempts` 表新增作答记录；上一题状态为 `answered`，下一题状态为 `ready`。 |
