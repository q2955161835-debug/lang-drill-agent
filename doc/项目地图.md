# 项目地图

最后更新：2026-06-08 14:25

## 项目目标
- 将 `语言学习-lang-drill-skill` 制作为可运行的语言学习训练 Agent（智能体），提供共享后端内核、CLI（Command Line Interface，命令行接口）和 Web（网页）前端。
- 当前公开简介重点面向英语四级/六级（CET-4/CET-6，大学英语四级/六级）与日语四级/六级（CJT4/CJT6，大学日语四级/六级）备考。

## 目录职责
- `backend/langdrill_agent/`：共享后端核心、API（Application Programming Interface，应用程序接口）、CLI（命令行接口）、服务层和 Agent（智能体）。
- `frontend/`：React（前端框架）+ Vite（前端构建工具）Web（网页）前端。
- `data/`：本地学习状态和示例数据。
- `try/`：测试与调试文件，可清理。
- `doc/`：本地维护记录与项目地图。

## 常用命令
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .[dev]
py -m langdrill_agent.cli init
py -m langdrill_agent.cli serve --reload
cd frontend
npm run dev
```
