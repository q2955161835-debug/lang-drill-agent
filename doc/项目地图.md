# 项目地图

最后更新：2026-06-03 18:14

## 项目目标

把 `语言学习-lang-drill-skill` 制作为三 Agent 协作的语言学习系统，支持命令行使用和网页前端完整使用。

## 目录职责

- `backend/langdrill_agent/`：共享后端内核，包含数据库、服务层、Prompt Engine（提示词引擎）、Task Router（任务路由器）、三 Agent、API（应用程序接口）和 CLI。
- `backend/langdrill_agent/migrations/`：SQLite（轻量数据库）schema。
- `frontend/`：React + Vite（前端构建工具）网页前端。
- `doc/`：项目地图、进展记录、架构说明。
- `try/`：测试和调试文件，可清理。

## 核心入口

- CLI：`py -m langdrill_agent.cli`
- API：`py -m langdrill_agent.cli serve --reload`
- Web：`cd frontend; npm run dev`

## 主要功能

- 首次初始化：供应商/API 设置提示、学习背景、学习目标、用户称呼、考纲与真题索引检查。
- 日常学习：聊天输入今日学习内容，系统生成当日面板，选择学习与复习内容，出题、判题、讲解、回写数据库、总结。
- 分支对话：拖选文本创建分支，默认不写回主会话，可合并为注释、错题解释、复习卡片或学习背景更新。
- 设置：模型提供商、token（令牌）统计、学习目标、学习背景、个性化提示词、agent 性格、思考等级、学习算法、隐私、联网、字体和主题。

## 数据流

用户输入进入 `TaskRouter` 后被转成任务；`OrchestratorAgent` 读取数据库状态并选择 prompt 模块；`QuestionAuthorAgent` 生成结构化题目并由 `QuestionValidator` 校验；`EvaluatorTutorAgent` 判题、讲解并更新学习状态。长期记录只以摘要、统计和检索片段进入 prompt。

## 关键依赖

- Python：FastAPI（Web API 框架）、Typer（CLI 框架）、Pydantic（数据校验）、SQLite（本地数据库）。
- 前端：React、TypeScript（类型化 JavaScript）、Vite、GSAP（GreenSock Animation Platform，动画库）、Phosphor Icons（图标库）。

## 环境账本

- `.env`：真实配置和密钥，禁止提交。
- `.env.example`：变量名、占位值和示例说明，随代码维护。
- 模型配置变量：`LANGDRILL_DEFAULT_PROVIDER`、`LANGDRILL_DEFAULT_MODEL`、`LANGDRILL_PROVIDER_BASE_URL`、`LANGDRILL_PROVIDER_API_KEY`。网页设置可写入本地 `.env`。
