# 项目地图

最后更新：2026-06-26 21:24

## 项目目标
- 将 `语言学习-lang-drill-skill` 制作为可运行的语言学习训练 Agent（智能体），提供共享后端内核、CLI（Command Line Interface，命令行接口）和 Web（网页）前端。
- 当前公开简介重点面向英语四级（CET-4，大学英语四级）、日语四级（CJT4，大学日语四级）、雅思（IELTS，国际英语语言测试系统）、托福（TOEFL，英语能力考试）与高考英语备考。

## 目录职责
- `backend/langdrill_agent/`：共享后端核心、API（Application Programming Interface，应用程序接口）、CLI（Command Line Interface，命令行接口）、服务层和 Agent（智能体）。
- `frontend/`：React（前端框架）+ Vite（前端构建工具）Web（网页）前端。
- `frontend/src/components/RightWorkbench.tsx`：右侧学习工作台，包含分支、手机映像、截图导入和语音预留入口；手机映像以 scrcpy（开源手机映像工具）+ adb（安卓调试桥）为底层集成方向。
- `data/`：本地学习状态和示例数据，SQLite（轻量数据库）文件不提交。
- `try/`：测试与调试文件，可清理；本轮新增模型配置回归测试。
- `doc/`：本地维护记录、项目地图、用户测试表和桌面打包说明。
- `src-tauri/`：Tauri（桌面壳）Windows 桌面封装骨架。

## 核心功能入口
- Web（网页）入口：`frontend/src/App.tsx`，负责三栏布局、主聊天、设置、初始化和右侧工作台接入。
- API（接口）入口：`backend/langdrill_agent/api.py`，提供 bootstrap（初始化加载）、chat（聊天学习）、branch（分支）、profile（用户档案）、model-config（模型配置）、exam/syllabus（考试与考纲）、phone-mirror（手机映像）、screenshot（截图文本解析）和 Anki（记忆卡工具）接口。

## 学习状态口径
- `study_sessions.exam_id` 记录会话所属考试；切换考试后，左侧会话列表、当日面板、题库统计和知识点进度按当前考试隔离。
- 当日学习面板按“日期 + 考试”聚合多个同日会话，避免同一天追加内容时题量口径割裂。
- 题目卡片只在后端返回 `active_question.status = ready`（待答题）时固定显示；答题提交会携带 `question_id`（题目编号）和 `selected_option`（选项），避免会话状态漂移时误触发重新出题。

## 考试与考纲
- 内置考试选项：英语四级、日语四级、雅思、托福、高考英语，以及自定义考试入口。
- 考纲更新改为手动检查；若内容年份未变化，提示已是最新考纲；若出现新年份，旧年份保留在考纲选择列表。
- 自定义考试设置预留考纲网址自动下载、手动导入本地文件、题型/分值/考试时间等补充字段。
- CLI（命令行接口）入口：`backend/langdrill_agent/cli.py`，提供 init（初始化）、serve（启动服务）、status（状态）和 chat（终端聊天）。

## 模型配置规则
- `.env` 是真实环境变量账本，只放本地真实配置并由 `.gitignore` 排除。
- `.env.example` 是假账本，只放变量名和占位值。
- `start.bat` 只写入开发期默认 MiMo（米魔）provider/model/base_url（供应商/模型/基础网址），不写入或覆盖 API Key（接口密钥）。
- 恢复默认设置会回到英语/CET-4（大学英语四级）和 MiMo（米魔）默认模型配置，并保留已有 `LANGDRILL_PROVIDER_API_KEY`。
- `mock`（本地模拟）是内部免密测试 provider（供应商），不会继承真实 Base URL/API Key（基础网址/接口密钥），避免冒烟测试污染真实模型配置。

## 常用命令
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .[dev]
py -m langdrill_agent.cli init
py -m langdrill_agent.cli serve --reload
cd frontend
npm run dev
```
