# Lang Drill Agent 项目地图

最后更新：2026-07-01 14:15

## 项目目标

Lang Drill Agent 是语言学习刷题训练 Agent（智能体），用于把长期学习、考试备考、题组生成、答题判分、错题回流、截图单词导入和间隔复习组织成可追踪的本地应用。

当前重点面向英语四级/六级（CET-4/CET-6，大学英语四级/六级）与日语四级/六级（CJT4/CJT6，大学日语四级/六级）备考，后续可扩展到自定义考试、雅思（IELTS，国际英语语言测试系统）、托福（TOEFL，英语能力考试）等场景。

## 系统分层

- 前端展示层：`frontend/`，React（前端框架）+ TypeScript（类型化 JavaScript）+ Vite（前端构建工具），负责三栏学习工作台、聊天、设置、当前题吸附卡片、已答题回顾卡片、右侧分支和导入工作台。
- 后端状态层：`backend/langdrill_agent/`，FastAPI（Web API 框架）+ Typer（CLI 框架）+ SQLite（轻量数据库），负责学习状态机、题组、作答、掌握度和配置。
- Agent（智能体）层：`agents.py`、`task_router.py`、`prompt_engine.py`、`providers.py`，负责任务路由、提示词组装、模型供应商适配和判题讲解。
- 上下文与统计层：`context.py`，负责当前会话上下文估算、自定义上下文容量、主动压缩、模型用量分布、近 30 天活动和 token（令牌）统计。
- 数据路径层：`data_paths.py`，负责用户数据目录、题目 SQLite（轻量数据库）路径状态、迁移、空库初始化和 `.env` 路径账本更新。
- 真题资产层：`paper_assets.py` 和 `papers/`，负责按考试类型保存原始试卷、解析 JSON（JSON 数据交换格式）、题型、章节和短摘录。
- 启动维护层：`start.bat`、`stop.bat`、`scripts/dev/`，负责 Windows 开发期一键启动、停止、端口清理、后台进程和日志。
- 文档验收层：`AGENTS.md`、`README.md`、`doc/验收标准.md`、`doc/manual-acceptance-checklist.md`、`doc/进展记录/`。

## 目录职责

- `backend/langdrill_agent/`：共享后端核心、API（接口）、CLI（命令行接口）、服务层和 Agent（智能体）。
- `backend/langdrill_agent/migrations/`：SQLite（轻量数据库）schema（数据库结构）初始化脚本。
- `frontend/src/App.tsx`：Web（网页）主入口，负责布局、聊天、设置、初始化、长期统计面板、右键菜单入口、当前题吸附显示、已答题回顾卡片和题目状态。
- `frontend/src/components/RightWorkbench.tsx`：右侧工作台，包含分支、手机映像、截图导入和语音预留入口。
- `frontend/src/components/ContextMenu.tsx`：主聊天消息与会话列表的右键菜单组件。
- `frontend/src/components/MarkdownText.tsx`：主聊天和分支消息的安全 Markdown（标记语言）渲染组件，支持加粗、内联代码、列表、标题和代码块。
- `backend/langdrill_agent/paper_assets.py`：历年真题原始文件存储、文本抽取、章节/题型/短摘录解析和解析 JSON（JSON 数据交换格式）写入。
- `backend/langdrill_agent/data_paths.py`：题目数据库文件夹状态、迁移当前库、初始化空库和默认参考数据补种。
- `papers/`：按考试类型分开的真题资产目录骨架；`raw/` 存原始试卷或粘贴文本，`parsed/` 存解析 JSON（JSON 数据交换格式），实际导入内容默认不提交。
- `scripts/dev/start-dev.ps1`：开发期一键启动主逻辑，适配中文路径、API Key（接口密钥）前缀规范化、日志重定向、后台进程和 HTTP（超文本传输协议）健康检查。
- `start.bat`：Windows 双击入口，只委托到 `scripts/dev/start-dev.ps1`。
- `stop.bat`：停止服务并清理 `5173` / `8000` 端口。
- `src-tauri/`：Tauri（桌面壳）Windows 桌面封装骨架。
- `~/.langdrill-agent/`：默认用户状态点目录，存放正式 SQLite（轻量数据库）学习库和后端日志。
- `data/`：历史项目内数据库位置，只作为旧库迁移来源或本地示例目录；数据库文件不提交。
- `data_backups/`：用户数据备份目录，不提交。
- `doc/`：架构说明、项目地图、验收标准、人工验收清单、桌面打包说明和进展记录。
- `try/`：自动测试、调试脚本和临时验证文件，可清理。
- `测试数据/`：正式运行路径迁出的开发/联调/污染数据，按时间戳分类保存，不提交。
- `archive/optimized-out/`：已从运行路径下线的旧模块归档，例如旧组词器和 Anki（记忆卡工具）导出集成。

## 学习状态口径

- 数据库是唯一正式学习状态来源；聊天上下文只作为交互记录，不作为权威学习记忆。
- `study_sessions.exam_id` 记录会话所属考试；切换考试后，会话列表、当日面板、题库统计和知识点进度按当前考试隔离。
- 当日学习面板按“日期 + 考试”聚合多个同日会话，避免同一天追加内容时题量口径割裂。
- 正式刷题流程必须先生成完整题组并写入 `questions`，再以吸附题卡展示当前 `ready`（待答题）题目；已答题不继续吸附，而是跟随助手讲解消息作为普通回顾卡片保留。
- 答题提交必须携带 `question_id`（题目编号）和 `selected_option`（选项），服务层写入 `attempts`（作答记录）并更新 `mastery_score`（掌握度）；API（接口）返回 `answered_question`（已答题快照），并写入助手消息 payload（附加数据），包含用户选择、选项文本和对错状态。
- 主聊天和右侧分支消息通过 `MarkdownText` 安全渲染模型返回的基础 Markdown（标记语言），只生成 React（前端框架）文本节点和受控标签，不直接注入 HTML（超文本标记语言）。
- 用户显式输入“下一题 / 继续 / 下一个”时，只读取当前题组下一道库存题，不重新初始化今日学习面板。
- 用户普通寒暄、学习建议咨询和澄清问题进入 `general_chat`，保留当前题卡但不调用组卷、不写 `questions`；只有明确词表、截图词表或显式“出题 / 练习 / 刷题 / 考我”等学习动作进入 `daily_drill`。
- 截图导入会把识别出的单词写入 `knowledge_items`，`source_scope='screenshot_import'`；点击“导入并开始练习”会创建独立截图词表会话、自动生成完整题组并返回当前题。
- 主聊天栏粘贴多行截图词表时，后端先用 `ScreenshotImportService` 识别词表；若识别到 3 个以上词条且不是选项题，复用截图导入流程创建独立截图词表会话、导入词表并自动生成题组；解析支持“单词独占一行 + 下一行释义”、`word n. 释义` 和 `word: 释义` 格式。
- 截图自动题组的内容池以本次截图词表为准，避免旧会话词汇污染；题目必须是考试式语境题，禁止退化为中文释义匹配词卡。英语考试题组的选项不得混入中文释义、日文字符、调试词或用户输入里的中文元信息。
- `PastPaperService` 使用 `exam_assets.asset_type='past_paper'` 保存历年真题试卷记录；默认按当前考试选择近 3 年真题，并在 `papers/<考试>/raw` 和 `papers/<考试>/parsed` 下创建来源清单/解析占位。用户可在设置的“考纲”页勾选试卷、手动导入本地文件或粘贴文本、重新解析，或创建联网搜索导入索引。
- 组卷时 `QuestionAuthorAgent` 把当前选中真题试卷、来源网站、解析摘要、章节结构、短摘录和已勾选题型放入 `past_paper_context`；模型必须参考这些解析结果生成题目，并在 `source_refs` 中记录对应真题来源边界。
- `LearningStatsService` 按当前考试聚合长期面板统计：题目完成/总数、去重词汇掌握/总数、整体作答正确率。
- 答题提交时程序先做客观判定和掌握度计算，再由 Evaluator Tutor（判题讲解 Agent）结合 `ContextService.prompt_context()`、用户学习背景、当前题目和程序判定生成个性化讲解；模型不可用时回退基础讲解并保留作答。
- `token_totals(session_id)` 返回累计输入/输出/总 token（令牌）、当前会话上下文估算、上下文容量上限、会话数、消息数、活跃天数、连续天数、模型分布和近 30 天活动；聊天响应必须传入当前 `session_id`，避免上下文容量显示为全局空上下文。
- `list_sessions_by_date()` 只返回已写入消息的非删除会话，新聊天在首条正式输入前不落库显示。

## 模型配置规则

- `.env` 是真实环境变量账本，只放本地真实配置并由 `.gitignore` 排除。
- `.env.example` 是假账本，只放变量名、占位值和说明。
- API Key（接口密钥）以纯密钥值为准；后端读取/保存时会清理常见 `apikey:` / `Bearer:` 粘贴前缀，非法请求头字符会转成可读配置错误。
- `LANGDRILL_MIGRATE_LEGACY_DB=1` 才从项目内历史 `data/langdrill_agent.db` 复制旧库；默认不复制，避免清空重测时新用户库被历史数据污染。
- 设置页“数据”页签和 CLI（命令行接口）`set-question-db-folder` 可把题目 SQLite（轻量数据库）迁移到自定义文件夹，或在目标文件夹初始化无学习记录空库；空库仍会补入默认考纲、每个内置考试近三年真题索引、模型配置和内置提示词模块。
- `LANGDRILL_ENABLE_LLMLINGUA=1` 时，主动压缩上下文可尝试使用可选依赖 LLMLingua；未启用或不可用时使用本地抽取式摘要兜底。
- `LANGDRILL_PAPER_ROOT` 指定历年真题原始文件和解析 JSON（JSON 数据交换格式）根目录，默认 `./papers`。
- `start-dev.ps1` 只写入开发期默认 MiMo（小米米魔）provider/model/base_url（供应商/模型/基础网址），不写入或覆盖 API Key（接口密钥）；保留密钥时会清理常见 `apikey:` / `Bearer:` 粘贴前缀。
- 恢复默认设置回到英语/CET-4（大学英语四级）和 MiMo（小米米魔）默认模型配置，并保留已有 `LANGDRILL_PROVIDER_API_KEY`。
- `mock`（本地模拟）是内部免密测试 provider（供应商），不会继承真实 Base URL/API Key（基础网址/接口密钥）；普通 Web bootstrap（网页初始化加载）遇到历史 mock 默认配置时会回到 MiMo（小米米魔）。

## 启动链路

一键启动：

```powershell
.\start.bat
```

内部流程：
1. 调用 `scripts/dev/start-dev.ps1`。
2. 检查或创建 `.venv`。
3. 安装/更新后端依赖，缺少前端依赖时执行 `npm install`。
4. 清理 `5173` / `8000` 端口。
5. 写入开发期默认模型配置，保留并规范化 API Key（接口密钥）。
6. 初始化用户档案和数据库。
7. 后台启动 FastAPI（Web API 框架）后端并等待 `http://127.0.0.1:8000/docs`。
8. 后台启动 Vite（前端构建工具）前端并等待 `http://127.0.0.1:5173`。
9. 两个健康检查都通过后打开浏览器。

运行日志：
- `logs/langdrill-backend.out.log`
- `logs/langdrill-backend.err.log`
- `logs/langdrill-frontend.out.log`
- `logs/langdrill-frontend.err.log`

## 常用命令

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .[dev]
py -m langdrill_agent.cli init
py -m langdrill_agent.cli data-paths
py -m langdrill_agent.cli set-question-db-folder "D:\LangDrill\user-data" --migrate
py -m langdrill_agent.cli backup-user-data
py -m langdrill_agent.cli serve --reload
cd frontend
npm run dev
```
