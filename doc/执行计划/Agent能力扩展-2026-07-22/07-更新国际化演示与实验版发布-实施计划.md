# 更新、国际化、演示站与实验版发布 Implementation Plan

状态：活动计划；正在实施第 07 阶段。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付中/英/日三语 UI、应用内签名更新中心、三语 README 与最新版 GitHub Pages 演示站，并把通过验收的完整能力发布为 `v1.0.0-experimental.1` 实验性大版本。

**Architecture:** 前端采用类型安全的静态词典和持久化 UI locale；后端返回稳定代码和结构化参数，不返回需要前端解析的中文业务句。Tauri 使用官方 updater 插件和 GitHub Release 签名清单；一个版本同步脚本维护 Python、npm、Cargo、Tauri、演示站和发布说明的一致版本。

**Tech Stack:** React、TypeScript、Vitest、Tauri 2 updater、Rust、PowerShell、GitHub Actions、GitHub Releases、GitHub Pages。

## Global Constraints

- UI locale 只影响应用壳、按钮、设置、状态、错误和帮助；不得修改模型回复语言、题目语言、用户自定义指令或学习资料。
- 支持 `zh-CN`、`en-US`、`ja-JP`；首次使用跟随系统，之后使用用户显式选择并全局持久化。
- README 三种语言互相可达；根 README 默认中文，英文与日文不是缩略占位页。
- 更新包和 `latest.json` 必须经过 Tauri updater 签名验证；签名私钥只存 GitHub Actions Secrets。
- `v1.0.0-experimental.1` 必须是 GitHub Pre-release，标题和正文同时标注实验版/Experimental/実験版。
- `演示web2` 只做脱敏静态模拟；用户明确要求的最新版同步仅允许从主前端单向同步 UI，保留演示 API mock，禁止连接真实后端。
