# 真实真题、蒸馏与自适应调度 Implementation Plan

状态：已完成并通过验收；2026-07-22。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用真实自动导入和解析的试卷替换占位索引，提供题目级检索、证据蒸馏和兼顾用户弱项、热门模式与冷门覆盖的练习调度。

**Architecture:** `past_paper_sources` 保存远程目录，真实文件进入 raw/parsed/structured；解析 Markdown 是可读资产，SQLite 是检索层。蒸馏只生成证据结论，`AdaptivePracticeScheduler` 单独执行带滚动覆盖约束的选题。

**Tech Stack:** Python、SQLite/FTS5、现有 MinerU/RapidOCR、httpx、Markdown、FastAPI、React。

## Global Constraints

- 远程目录项不计入真实试卷数量。
- 不虚构年份、套卷、答案或来源；不绕过登录、付费、验证码和反爬。
- 用户导入内容优先级高于真题频率。
- 冷门保底仅适用于已启用且系统支持的题型；当前听力继续排除。
- 蒸馏结论没有足够证据时必须返回 `insufficient_evidence`。
