# 分层记忆 Implementation Plan

状态：已完成；2026-07-22 L3（三级）验收通过。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立本地优先、证据驱动、可审核、可配置和可替换 Provider 的长期记忆，为所有模式提供受控召回。

**Architecture:** 记忆候选先经过未来价值、新颖性、事实性和秘密扫描，再提交为带证据、有效期和版本的记忆。小型 Core Memory 常驻，较大 Semantic/Episodic/Procedural/Temporal Memory 按需混合检索。

**Tech Stack:** Python、SQLite/FTS5、计划 02 的 Embedding/RRF、Pydantic、FastAPI、React。

## Global Constraints

- Mastery、attempts、profile 和 questions 是正式事实；记忆不能覆盖它们。
- 单次错题默认不能生成长期弱项。
- 凭据值永不进入候选、记忆、向量索引或日志。
- 总开关关闭后停止捕获和召回，但不自动删除数据。
- 同一时间只允许一个主写 Provider。

    repo = MemoryRepository(conn)
    item = repo.commit(candidate("User prefers concise explanations"))

    revisions = repo.revisions(item.id)
    assert updated.content.endswith("with examples")
    assert [r.operation for r in revisions] == ["ADD", "UPDATE"]


def test_supersede_keeps_old_memory(conn):

    new = repo.supersede(old.id, candidate("Exam deadline is 2026-10-01"))
