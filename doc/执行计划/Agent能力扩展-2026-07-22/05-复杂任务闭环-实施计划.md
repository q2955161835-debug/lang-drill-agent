# 复杂任务闭环 Implementation Plan

状态：已完成；2026-07-22 L3（三级）自动验收通过，可进入第 06 阶段。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox（步骤使用复选框） (`- [x]`) syntax for tracking（语法用于进度追踪）。

**Goal:** 为明确的多步骤行动任务提供计划、执行、证据、验证、重试、重规划和重启恢复，同时不干扰正式学习任务。

**Architecture:** `CapabilityIntentClassifier` 仅识别行动需求；`AgentRunPlanner` 生成结构化计划，`AgentRunExecutor` 按步骤调用注册工具并持久化状态，`AgentRunVerifier` 决定继续、重试、重规划或结束。

**Tech Stack:** Python、SQLite、FastAPI SSE、Pydantic、现有 Provider、React。

## Global Constraints

- 正式学习意图始终先由现有 TaskRouter 处理。
- Agent Run 中断不能修改当前题组的活动状态。
- 每步有完成条件和证据；模型口头声称完成不算完成。
- 工具调用在计划 06 前只使用注册的安全领域工具和测试工具。
