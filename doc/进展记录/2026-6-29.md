错误汇报：
- 问题：旧 `start.bat` 打印“已启动”，但前后端实际没有监听端口。原因：后台 `Start-Process` 命令未被健康检查约束，进程启动失败时脚本仍继续打开浏览器。解决方案：将启动逻辑迁入 PowerShell 启动器，启动后轮询 HTTP 地址并在失败时输出日志尾部。
- 问题：`scripts/dev/start-dev.ps1` 首版包含中文字符串，在 Windows PowerShell 5.1 下通过 `-File` 读取 UTF-8 no BOM 文件时被错误解码并触发语法错误。解决方案：启动器正文改为 ASCII 内容，避免脚本解析依赖 BOM。
- 问题：`start.bat` 经补丁写入后变成 LF 换行，`cmd.exe` 解析多行命令失败。解决方案：恢复为 CRLF Windows 换行。
- 问题：旧测试仍要求 `WindowStyle Hidden` 出现在 `start.bat`。原因：后台启动职责已经迁移到 `scripts/dev/start-dev.ps1`。解决方案：更新测试为检查入口委托和启动器实现。
- 问题：Windows PowerShell 5.1 的 `Set-Content -Encoding UTF8` 可能给 `.env` 写入 BOM。解决方案：改用 `[System.IO.File]::WriteAllLines` 和 `UTF8Encoding(false)` 写入 `.env`，并只检查字节头，不输出真实密钥内容。
