### 问题-原因-解决方案
- 问题：`start.bat` 明文写入 API Key（接口密钥）。原因：启动脚本将开发期模型配置和密钥一起覆盖写入 `.env`。解决方案：移除 key（密钥）写入逻辑，仅保留 MiMo（米魔）默认 provider/model/base_url（供应商/模型/基础网址）。
- 问题：恢复默认设置会清空已有 API Key（接口密钥）。原因：`reset_defaults` 使用空 key（密钥）和 `clear_empty=True` 写 `.env`。解决方案：恢复默认只写 provider/model/base_url（供应商/模型/基础网址），保留已有 key（密钥）。
- 问题：写 `.env` 后当前进程仍可能返回旧模型配置。原因：`python-dotenv`（环境变量加载库）加载过的进程环境变量优先级覆盖了新 `.env`。解决方案：`_write_env` 写文件后同步更新当前进程环境变量。
- 问题：mock（本地模拟）模式会继承真实 Base URL/API Key（基础网址/接口密钥）状态。原因：`mock` 不在正式 provider（供应商）查找表中，回落到了 DeepSeek（深度求索）并读取真实环境变量。解决方案：增加内部 mock（本地模拟）provider（供应商）处理，并让 `current_with_secret` 在 mock（本地模拟）模式不携带真实 key（密钥）。
- 问题：复测时 8000 端口存在热重载残留进程，导致新旧代码响应不一致。原因：旧 `--reload` 父子进程残留。解决方案：最终验证改用独立 8010 端口启动最新后端，并在测试表中提示人工测试前先运行 `stop.bat`。
- 问题：从 Git Bash（命令行）执行 `stop.bat` 时出现 `find` 和 `timeout` 命令冲突。原因：Git Bash（命令行）环境里的同名命令覆盖了 Windows（视窗系统）系统命令。解决方案：`start.bat` 和 `stop.bat` 显式调用 `%SystemRoot%\System32` 下的 `netstat/findstr/taskkill/ping`，并用 `ping` 替代 `timeout` 等待。
