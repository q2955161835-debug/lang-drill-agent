#### 关键决策

1. **Vite 多入口 + iframe 隔离**：landing 与 mock 前端样式差异巨大（Framer 风 vs 卡通果冻风），用独立 HTML 入口 + iframe 隔离避免 CSS 互相污染
2. **mock API 策略**：保留 frontend 整个 src/ 不动，仅替换 api.ts 为返回固定数据的本地实现，UI 渲染 100% 保真
3. **GitHub Pages base 路径**：base 设为 `/lang-drill-agent/`，可通过 `VITE_BASE_PATH=./` 覆盖用于本地预览
4. **素材虚构**：skills 路径虚构为 `~/LangDrill/skills/skill1`、`~/LangDrill/skills/skill2`，data_paths 虚构为 `~/LangDrill/user-data`，不暴露真实主机位置
5. **图片路径**：hero-bg-texture.jpg 使用 inline style + `import.meta.env.BASE_URL` 确保在 GitHub Pages 子路径下正确加载
