# Lang Drill Agent v1.0.0-alpha.1 实验版 / Experimental / 実験版

> 本版本为实验性预发布（Experimental Prerelease）。正式学习流程保持稳定，但创造模式、签名更新中心、三语界面与演示站同步均为实验性能力，可能存在不稳定。升级前请务必备份用户数据目录。

- 标签：`v1.0.0-alpha.1`
- 渠道：`experimental`（GitHub Pre-release）
- 发布日期：2026-07-23
- 适用平台：Windows x64（桌面版）/ 现代浏览器（Web 开发版）/ GitHub Pages（演示站）

## 亮点 / Highlights

1. **三语界面（中 / 英 / 日）**：应用壳、设置、状态、错误、帮助文案全面国际化；首次启动跟随系统语言，用户显式选择后全局持久化；模型回复、题目和自定义指令语言不受影响。
2. **应用内签名更新中心**：桌面版接入 Tauri 官方 updater 插件，通过签名 `latest.json` 清单检查、下载、安装和重启；签名私钥只存 GitHub Actions Secrets，安装由用户主动触发，失败可重试并查看日志。
3. **实验版发布资料**：单一 `VERSION` 文件作为规范版本来源，`set-version.ps1` 确定性更新所有清单，`verify-version.ps1` 在 CI 中阻断不一致发布。
4. **三语 README**：根 `README.md`、`README.en.md`、`README.ja.md` 互相可达，覆盖安装、Web/桌面使用、创造模式警告、知识库、记忆、真题版权边界、更新、实验版状态和 License。
5. **演示站同步**：`演示web2` 同步最新主应用 UI 模拟，含实验版元数据、更新中心、记忆控制、RAG 引用与创造模式档位演示，全部数据为脱敏静态模拟，不连接真实后端。

## 迁移行为 / Migration

- **数据库**：本版本不修改 SQLite schema，无需迁移。运行库继续写入 `%APPDATA%\Lang Drill Agent\data`（桌面版）或项目内 `data/`（Web 开发版）。
- **配置**：`.env` 真实账本和 `LANGDRILL_ENV_FILE` 路径不变。桌面版配置仍写入 `%APPDATA%\Lang Drill Agent\.env`。
- **版本号**：`VERSION` 文件引入规范版本号；旧的 `0.1.x` 桌面包可继续使用，但不会收到应用内更新提示，需手动下载新版本安装。
- **界面语言**：首次升级后界面语言跟随系统；可在 设置 → 语言 切换。

## 创造模式警告 / Creative Mode Warning

创造模式是可选的实验性 Agent 能力，默认关闭，不影响正常刷题与学习流程。开启后可调用本地 Pi 运行时执行目录整理、文件操作等通用任务，并提供逐次审批、智能审批和完全访问三档权限。

> ⚠️ 警告：创造模式的通用权限可以修改本机文件。请仅在理解风险后启用，并优先使用逐次审批档位。创造模式仍为实验性，模型不可用时回退本地规则兜底，不阻断正式学习。

## Pi 修复 / Pi Runtime Repair

桌面版内置 Pi 运行时检测与一键修复：
- 设置 → 创造模式 显示运行时状态（就绪 / 未就绪）。
- 未就绪时点击"一键修复"会自动准备运行时；修复日志写入用户目录。
- 修复失败时显示失败代码、已尝试步骤、日志路径和手动安装命令，便于离线恢复。

## 真题来源限制 / Past Paper Source Limits

- 真题资产仅作为本地参考：默认只保留考试索引和短摘录。
- 完整真题文件保存在用户本地 `papers/<考试>/raw` 目录，不进入默认发布资产。
- 出题 Agent 参考真题题型与风格，不复刻或长段引用完整真题原文。
- 请用户自行确保导入的真题内容符合版权与使用许可。

## 记忆与 RAG 控制 / Memory & RAG Controls

- **分层记忆**：维护用户画像、学习目标、薄弱项和长期偏好；写入本地数据库，可在 设置 → 记忆 查看与清除。
- **知识库（RAG）**：用户可导入本地文档建立知识库；答题讲解和分支对话可引用知识库来源，引用结果带可核验来源标注。
- 记忆默认只作为辅助上下文，除非用户询问学习设置、制定计划或画像与当前错误直接相关。

## 更新签名 / Update Signing

- 桌面版更新包通过 Tauri updater 插件自动验证 minisign 签名。
- 公钥已写入 `src-tauri/tauri.conf.json` 的 `plugins.updater.pubkey`。
- 签名私钥只存 GitHub Actions Secrets（`TAURI_SIGNING_PRIVATE_KEY`、`TAURI_SIGNING_PRIVATE_KEY_PASSWORD`），不在本地或仓库中出现。
- 更新检查与安装均由用户主动触发；失败可重试、打开日志目录或前往 GitHub Release 手动下载。
- Web 开发版返回显式 `desktop_only` 状态，不调用不可用的 Tauri API。

## 备份与回退 / Backup & Rollback

升级前请备份：

```powershell
# 桌面版用户数据目录
Copy-Item -Recurse "%APPDATA%\Lang Drill Agent" "D:\Backup\LangDrill-Pre-1.0.0-alpha.1"
```

回退步骤：
1. 卸载新版本（控制面板 → 应用 → Lang Drill Agent → 卸载）。
2. 从 GitHub Release 下载旧版本 `Lang.Drill.Agent_0.1.2_x64-setup.exe` 并安装。
3. 如有需要，从备份恢复 `%APPDATA%\Lang Drill Agent` 目录。

> Web 开发版无安装步骤，回退只需 `git checkout` 到旧 commit 即可。

## 已知问题 / Known Issues

1. **未代码签名**：首版桌面安装包为 unsigned 内测包，Windows 可能提示未知发布者，确认来源后继续安装。
2. **听力题预留**：所有考试中的听力 / Listening 题型只作为预留项展示，默认关闭、不可勾选，不进入实际组卷。
3. **更新中心 Web 模式**：Web 开发版更新中心显示 `desktop_only`，不会调用 Tauri API；真实更新检查只在桌面版可用。
4. **演示站数据**：`演示web2` 是静态模拟站点，所有"模型回复"为固定模拟内容，不连接真实后端。
5. **创造模式实验性**：Pi 运行时不可用时回退本地规则兜底，可能影响部分通用任务执行。
6. **三语翻译**：日文翻译为人工校对，如有不通顺请反馈。
