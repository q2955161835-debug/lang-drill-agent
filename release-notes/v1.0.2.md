# Lang Drill Agent v1.0.2 实验版 / Experimental / 実験版

> 本版本是当前实验发布，内容以稳定性与数据可靠性加固为主，没有新增用户可见功能。`v1.0.1` 作为上一个实验版继续保留，`v0.1.2` 仍是稳定版。

- 标签：`v1.0.2`
- 渠道：`experimental`（GitHub Pre-release）
- 发布日期：2026-07-26
- 适用平台：Windows x64

## 亮点 / Highlights

1. **答题记录不再会因模型故障丢失**。判题讲解的作答写入原先排在模型调用之后，一次未被归一化的网络超时会同时丢掉作答记录、题目状态、掌握度事件和审计标记，而用户消息已经落库，聊天记录里会出现「答了但没有作答记录」。现在程序判定先落库，模型成功后再回写讲解，成功路径的最终结果不变。
2. **模型供应商的失败被统一归一化**。`httpx` 的超时、连接错误和响应体解析错误都不继承 `RuntimeError`，此前会绕过全部兜底逻辑；代理在 HTTP 200 下返回 HTML 错误页也会直接抛异常。现在统一转换为 `ModelProviderError`，超时、连接失败、非法 JSON 和结构不符都会走到可读的错误提示或程序兜底。
3. **MinerU 解析超时能正确回退本地 OCR**。`subprocess.TimeoutExpired` 不属于 `RuntimeError`，此前会跳过 RapidOCR 兜底导致图片导入直接失败；现已归一化。
4. **上传与导入不再冻结后端**。截图/文件抽取、真题导入、知识库导入和资源暂存四类接口原先在事件循环上直接执行子进程、OCR 和数据库初始化，会让所有其它接口（含桌面版健康检查）一起卡住；现已移入线程池。
5. **数据层性能加固**。补齐 11 条核心索引（此前 20 张核心表没有任何二级索引）、把每行写入各自 fsync 改为 WAL 下的 `synchronous=NORMAL`、并让数据库初始化每进程只执行一次（此前 102 个接口调用点会各自重跑一遍迁移与提示词播种，使只读接口也去抢写锁）。
6. **聊天记录渲染不再随会话变长而变卡**。消息组件补上 memo，Markdown 解析结果缓存，输入框打字不再重解析整份聊天记录。
7. **桌面版 Agent 运行进度修复**。运行事件的 SSE 订阅原先用相对地址，在打包版中解析不到本地后端，进度卡片会静默冻住。
8. **创造模式权限收紧**。`smart_approval` 档位原先按命令首个 token 判断只读，而实际以 `shell=True` 执行整串命令，因此 `ls && curl -T .env ...` 之类的串联命令会无审批执行；工作区内任意路径的读写也自动放行，包括开发期 `.env`。现在含 shell 元字符的命令与敏感路径（`.env*`、凭据文件、可执行脚本、`scripts/`、`.git/`、`.github/`）一律需要人工确认。
9. **仓库泄露口修补**。`papers/**/structured/*` 此前不在 `.gitignore` 覆盖范围内，而该目录存放完整结构化真题解析结果（题干、选项、答案、篇章）；轮转日志 `logs/*.log.*` 同样未被忽略。
10. **CI 覆盖补齐**。前端 55 项 Vitest、pi-bridge 协议测试和桌面壳 `cargo check` 此前只在发布打标签时才运行，普通 push/PR 完全不执行；现已纳入常规 CI，Python 代码检查范围也从 `backend` 扩到 `backend tests scripts`。

## 迁移行为 / Migration

- 现有 SQLite 学习数据继续使用原运行库，**不需要任何手动迁移**。新增索引在启动时自动创建，是纯增量操作，不改变表结构、不删除数据。
- 索引刻意不通过 `.sql` 迁移文件创建：数据库初始化时迁移先于补列执行，而早期版本建立的库要靠补列步骤补上 `study_sessions.exam_id`，迁移脚本引用该列会在这些老库上失败。索引统一在补列之后创建，并已针对该老库场景验证。
- 桌面配置和用户数据继续保存在 `%APPDATA%\Lang Drill Agent`。
- 可从 `v0.1.2` 或 `v1.0.1` 直接安装；升级前建议备份用户数据。
- 判题作答记录的生命周期有变化：`attempts` 行现在先写入程序判定，模型讲解成功后再回写。成功路径的最终数据与此前一致，但如果有外部脚本依赖「`attempts` 行出现即代表讲解已完成」，需要相应调整。仓库内不存在这样的依赖。

## 更新签名 / Update Signing

- Tauri 更新包使用 minisign 签名。
- 公钥保存在 `src-tauri/tauri.conf.json`。
- 私钥和密码只保存在 GitHub Actions Secrets，不写入仓库或安装包。

## 备份与回退 / Backup & Rollback

升级前备份 `%APPDATA%\Lang Drill Agent`。如果需要回退：

1. 卸载 `v1.0.2`。
2. 从演示页或 GitHub Release 下载 `v1.0.1` 上一实验版或 `v0.1.2` 稳定版。
3. 必要时恢复已备份的用户数据目录。

数据层改动为纯增量：回退安装包后，已建立的索引会留在用户库中但不影响旧版本运行；`synchronous` 是连接级设置，回退即恢复原值。

## 已知问题 / Known Issues

1. Windows 安装包尚未进行商业代码签名，系统可能显示"未知发布者"。
2. 创造模式、三语界面、应用内更新和在线演示仍属于实验能力。
3. 本地嵌入模型首次使用需要用户下载模型文件，下载耗时和磁盘占用取决于所选模型。
4. 听力题和语音模型尚未接入。
5. `演示web2` 是脱敏静态演示，不连接真实后端。
6. 索引带来的查询收益与累积学习历史成正比。数据量很小时（新装或使用不久）感知不到差别；本次实测在约三个月每日使用量的数据上，会话列表与每题最近作答查询有一个数量级的改善。
7. 当日词汇查询仍未走索引：其条件 `DATE(created_at,'localtime')=?` 属于 non-sargable 写法，索引只能过滤考试维度。改为半开区间涉及本地时区与 UTC 边界换算，为避免静默改变当日词汇计数，本版未改动。
8. MinerU 解析的单次超时仍为 900 秒（重试 2 次）。超时现在能正确回退本地 OCR，但等待时间偏长，将在后续版本调整。
9. 设置页仍会在打开时预加载四个隐藏面板，触发 8 个当前页签用不到的请求。
10. 出题 Agent 因模型失败走规则兜底时，不会写入 `model_calls` 审计台账。

## 验证摘要 / Verification Summary

- 新增 73 项后端回归测试，覆盖索引与初始化守卫、供应商异常归一化、作答记录不丢失、MinerU 超时回退、阻塞调用离开事件循环，以及创造模式的链式命令与敏感路径判定。每一项均先在修复前的代码上确认失败，再在修复后确认通过。
- `pytest tests` 由 334 项增至 407 项，全部通过；Ruff 检查范围扩大后通过。
- 前端 Vitest 55 项、pi-bridge 5 项、`cargo check`、演示站生产构建与 mock 逐字节一致性门禁全部通过，并首次在常规 CI 中执行。
- 应用实跑验收在完全隔离的环境中完成（不使用任何真实密钥）：以不可达地址制造真实连接错误验证兜底路径，以本地 stub 验证模型成功路径；全程零 5xx、零未捕获异常、前端零控制台报错。
- 详细验收记录见仓库内 `doc/验收/任务/验收-2026-07-26-数据层与韧性加固.md`（该目录不随仓库发布）。
