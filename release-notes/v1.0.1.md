# Lang Drill Agent v1.0.1 实验版 / Experimental / 実験版

> 本版本是当前实验发布。`v1.0.0-alpha.2` 作为 v1.0.0 系列历史版本继续保留，正式学习流程保持稳定。

- 标签：`v1.0.1`
- 渠道：`experimental`（GitHub Pre-release）
- 发布日期：2026-07-25
- 适用平台：Windows x64

## 亮点 / Highlights

1. 真题库与知识库新增文件选择、拖拽暂存、预览解析、确认导入和可审计导入记录，截图仍可作为来源。
2. 知识库 RAG（向量增强检索）可由用户主动开关，并支持本地、云端和关闭三种嵌入方式。
3. 默认推荐轻量 Qwen 嵌入模型；支持搜索 Hugging Face 嵌入模型、查看详情并由用户主动下载或删除本地模型。
4. 记忆设置收敛为快速、标准、深入三挡：标准预算为 10,000 token，深入模式不设置硬上限。
5. 记忆分组、上下文预算和 RAG 引用进入统一的可验证 API 与前端设置流程，并补齐失败回退与离线可用性。
6. `演示web2` 保持原有视觉风格，下载区同步展示 `v0.1.2` 稳定版、`v1.0.1` 当前实验版和 v1.0.0 系列历史版本；在线体验入口仍为实验版。
7. 桌面安装包递归携带完整后端包，新增后端模块不再因资源清单遗漏而导致安装后启动失败。

## 迁移行为 / Migration

- 现有 SQLite 学习数据继续使用原运行库；启动时会按现有迁移机制补齐资源导入、嵌入配置和记忆设置所需结构。
- 桌面配置和用户数据继续保存在 `%APPDATA%\Lang Drill Agent`。
- 可从 `v0.1.2` 或 `v1.0.0-alpha.2` 直接安装；升级前建议备份用户数据。
- 本地嵌入模型不会自动下载，是否下载以及使用哪个 Hugging Face 或云端模型完全由用户决定。

## 更新签名 / Update Signing

- Tauri 更新包使用 minisign 签名。
- 公钥保存在 `src-tauri/tauri.conf.json`。
- 私钥和密码只保存在 GitHub Actions Secrets，不写入仓库或安装包。

## 备份与回退 / Backup & Rollback

升级前备份 `%APPDATA%\Lang Drill Agent`。如果需要回退：

1. 卸载 `v1.0.1`。
2. 从演示页或 GitHub Release 下载 `v1.0.0-alpha.2` 历史版本或 `v0.1.2` 稳定版。
3. 必要时恢复已备份的用户数据目录。

## 已知问题 / Known Issues

1. Windows 安装包尚未进行商业代码签名，系统可能显示“未知发布者”。
2. 创造模式、三语界面、应用内更新和在线演示仍属于实验能力。
3. 本地嵌入模型首次使用需要用户下载模型文件，下载耗时和磁盘占用取决于所选模型。
4. 听力题和语音模型尚未接入。
5. `演示web2` 是脱敏静态演示，不连接真实后端。

## 验证摘要 / Verification Summary

- 版本清单一致性、发布工作流和下载渠道契约纳入自动测试。
- Python 测试与 Ruff 检查作为发布闸门。
- React/Vitest、演示站测试和生产构建作为发布闸门。
- Pi bridge、Rust/Tauri 检查和签名安装包构建作为发布闸门。
