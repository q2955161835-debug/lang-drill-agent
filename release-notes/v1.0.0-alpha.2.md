# Lang Drill Agent v1.0.0-alpha.2 实验版 / Experimental / 実験版

> 本版本为实验性预发布。正式学习流程保持稳定，创造模式、签名更新中心、三语界面与演示站仍属于实验能力。

- 标签：`v1.0.0-alpha.2`
- 渠道：`experimental`（GitHub Pre-release）
- 发布日期：2026-07-24
- 适用平台：Windows x64

## 亮点 / Highlights

1. 包含完整的 Web、FastAPI 与 Tauri 桌面学习工作台。
2. 修复桌面安装包遗漏后端子包的问题，知识库、记忆、真题、创造模式和运行时路由可随安装包部署。
3. 更新 Tauri updater 公钥，使安装包内置公钥与 GitHub Actions 签名私钥匹配。
4. GitHub Actions 自动构建并上传 NSIS 安装包、更新签名、`latest.json` 和校验和。

## 迁移行为 / Migration

- SQLite schema 未变化，不需要数据库迁移。
- 桌面配置和用户数据继续保存在 `%APPDATA%\Lang Drill Agent`。
- 可从 `0.1.2` 或早期实验版直接安装；建议升级前备份用户数据。

## 更新签名 / Update Signing

- Tauri 更新包使用 minisign 签名。
- 公钥保存在 `src-tauri/tauri.conf.json`。
- 私钥和密码只保存在 GitHub Actions Secrets，不写入仓库或安装包。

## 备份与回退 / Backup & Rollback

升级前备份 `%APPDATA%\Lang Drill Agent`。如果需要回退：

1. 卸载 `v1.0.0-alpha.2`。
2. 从 GitHub Release 下载并安装上一版本。
3. 必要时恢复已备份的用户数据目录。

## 已知问题 / Known Issues

1. Windows 安装包尚未进行商业代码签名，系统可能显示“未知发布者”。
2. 创造模式、三语界面和应用内更新仍是实验能力。
3. 听力题和语音模型尚未接入。
4. `演示web2` 是脱敏静态演示，不连接真实后端。

## 验证摘要 / Verification Summary

- Python 测试与 Ruff 检查通过。
- React/Vitest 测试和生产构建通过。
- Pi bridge 测试与 Rust/Tauri 检查通过。
- Windows VM 安装、后端健康检查和卸载流程通过。
